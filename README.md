# 反抄袭检测工具

用于批量分析 Word（`.docx`）文档的相似内容，包含图形界面、基础检测和增强文字检测。程序仅使用 Python 标准库，无需安装第三方依赖。

## 功能

- **基础检测**：分析文档作者和时间等元数据；检测完全相同的段落和重复图片。
- **增强检测**：过滤常见模板内容，并通过文本归一化、N-gram 指纹、句子相似度及 Word 修订会话 ID（rsid）辅助发现相似内容。
- **图形界面**：选择文档文件夹后运行综合检测，并查看生成的报告。

## 运行

需要 Python 3.8 或更高版本。将待检测的 `.docx` 文件放在同一文件夹中，并至少准备两份文档进行比较。

启动图形界面：

```powershell
python anti_plagiarism_tk.pyw
```

也可以分别运行命令行程序：

```powershell
python anti_plagiarism_tool.py
python anti_plagiarism_enhanced.py "D:\提交文档"
```

增强版支持可选的模板白名单文件（每行一条模板内容）：

```powershell
python anti_plagiarism_enhanced.py "D:\提交文档" --template "D:\模板.txt"
```

## 检测结果

程序会在当前工作目录生成 CSV 报告，可用 Excel 打开。基础检测报告包括元数据、段落匹配和图片匹配；增强检测报告包括模板清单、精确匹配、指纹匹配、句级匹配和 rsid 分析。基础图片检测还会提取图片到 `temp_word_images` 临时目录。

## 注意

检测结果用于筛查和辅助复核，不应单独作为认定抄袭的依据。模板内容、文档格式差异、图片编辑以及元数据可修改等因素都可能影响结果；请结合报告中的证据人工核查。详细用法和局限请参阅两份“使用说明”文档。
